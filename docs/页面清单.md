# 蜀韵·智游 · 页面清单

> 项目：shuyun-travel（Spring Boot 3 多模块 + Vue3）
> 前端工程：`shuyun-vue/`　路由入口：`src/router/index.ts`（聚合前台 + 用户后台 + 管理后台）

---

## 一、前台（用户端）

| URL | 对应文件 | 功能说明 |
|---|---|---|
| `/` | `src/views/Home.vue` | 首页：整屏滚动叙事（首屏大字 + 热门景点 + 八大文化 + AI 入口），GSAP + Lenis 驱动 |
| `/login` | `src/views/Login.vue` | 登录 / 注册（JWT，密码 BCrypt 加密） |
| `/scenic` | `src/views/Scenic.vue` | 景点列表：城市/类型/排序筛选 + 关键词搜索 + 分页（真实接口） |
| `/scenic/:id` | `src/views/ScenicDetail.vue` | 景点详情：轮播大图、图标信息卡（地址/开放时间/门票/官网）、图片墙、评论占位、同城推荐 |
| `/food` | `src/views/Food.vue` | 美食列表：分类胶囊 + 搜索 + 分页 |
| `/food/:id` | `src/views/FoodDetail.vue` | 美食详情：简介/历史故事两栏、辣度、店铺深色地图卡、同类推荐 |
| `/culture` | `src/views/Culture.vue` | 文化列表：分类筛选 + 卡片墙 + 文化时间轴 |
| `/culture/:id` | `src/views/CultureDetail.vue` | 文化详情：正文 + 相关景点/人物卡 + 图片集 + 视频（B站内嵌）+ 同分类推荐 |
| `/heritage` | `src/views/Heritage.vue` | 非遗列表：类别/级别下拉筛选 + 首字色卡（无封面图方案）+ 分页 |
| `/heritage/:id` | `src/views/HeritageDetail.vue` | 非遗详情：杂志式拼贴图集 + 横向 4 列信息卡 + 视频 + 同类推荐 |
| `/assistant` | `src/views/Assistant.vue` | AI 管家：女娲智能体 SSE 流式对话、会话历史、行程生成 |
| `/profile` | `src/views/Profile.vue` | 个人中心：可折叠侧边栏（我的行程/收藏/历史/笔记/账号设置），状态持久化 |
| `/screen` | `src/screen/DataScreen.vue` | 数据大屏：ECharts GL 3D 四川地图 + 飞线 + 实时数据（WebSocket） |

**前台公共布局**：`src/layouts/DefaultLayout.vue`（透明悬浮导航 + 抽屉式移动端菜单 + 聚合搜索）

---

## 二、用户后台（`/user/**`，需登录）

| URL | 对应文件 | 功能说明 |
|---|---|---|
| `/user/overview` | `src/user/views/UserOverview.vue` | 概览：个人统计 + 最近足迹 |
| `/user/trips` | `src/user/views/MyTrips.vue` | 我的行程列表 |
| `/user/collections` | `src/user/views/MyCollections.vue` | 我的收藏（景点） |
| `/user/notes` | `src/user/views/MyNotes.vue` | 我的笔记（富文本） |
| `/user/history` | `src/user/views/MyHistory.vue` | 浏览历史 |
| `/user/feedback` | `src/user/views/MyFeedback.vue` | 问题反馈提交/列表 |
| `/user/settings` | `src/user/views/AccountSettings.vue` | 账号设置（资料 / 改密） |

**布局**：`src/user/layouts/UserConsoleLayout.vue`　**路由**：`src/user/router/userConsole.ts`

## 三、管理后台（`/admin/**`，需 admin_token）

| URL | 对应文件 | 功能说明 |
|---|---|---|
| `/admin/login` | `src/admin/views/AdminLogin.vue` | 后台登录（独立全屏） |
| `/admin/dashboard` | `src/admin/views/Dashboard.vue` | 仪表盘：核心指标 + 图表 + 活动时间线 |
| `/admin/users` | `src/admin/views/UserManage.vue` | 用户管理（列表 / 详情 / 行为） |
| `/admin/scenic` | `src/admin/views/ScenicManage.vue` | 景点管理（增删改查 + 图片） |
| `/admin/culture` | `src/admin/views/CultureManage.vue` | 文化管理 |
| `/admin/trips` | `src/admin/views/TripManage.vue` | 行程管理 |
| `/admin/ai-chat` | `src/admin/views/AiChatManage.vue` | AI 对话管理（会话列表 + 消息） |
| `/admin/behavior` | `src/admin/views/UserBehavior.vue` | 用户行为统计 |
| `/admin/feedback` | `src/admin/views/FeedbackManage.vue` | 问题反馈处理 |
| `/admin/audit` | `src/admin/views/ContentAudit.vue` | 内容审核（笔记 / 反馈 / 订阅） |
| `/admin/backup` | `src/admin/views/DataBackup.vue` | 数据备份与恢复 |

**布局**：`src/admin/layouts/AdminLayout.vue`（深色控制台 + 侧边栏）　**路由**：`src/admin/router/admin.ts`
**公共组件**：`src/admin/components/DataTable.vue`（后台统一表格基座：骨架屏 / 空态 / 分页）
