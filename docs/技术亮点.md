# 蜀韵·智游 · 技术亮点

> 8 个可写进答辩 PPT 的技术亮点，含实现思路与对应页面/接口。

---

## 1. 女娲智能体 SSE 流式接入

- **一句话**：AI 管家对话采用 SSE 流式输出，回答逐字上屏，交互体验接近真人对话。
- **实现方式**：后端 `shuyun-ai` 模块通过 Spring WebFlux `WebClient` 以流式方式请求女娲智能体平台，将 `text/event-stream` 分片透传给前端；前端用 `fetch` + `ReadableStream` 增量解析，逐段 `append` 到消息气泡（兼容 Markdown 渲染），并对限流/异常做重试与降级。
- **对应页面/接口**：`/assistant`（`src/views/Assistant.vue`）；接口 `POST /api/ai/chat`（SSE）、`GET /api/ai/sessions`、`GET /api/ai/history`。

## 2. 主动式出行关怀（天气 / 客流定时推送）

- **一句话**：系统不等用户来问，主动推送天气与客流提醒，变"被动查询"为"主动关怀"。
- **实现方式**：后端 Spring `@Scheduled` 定时任务聚合天气（外部 API）与客流/行为数据，经 WebSocket 主动下发；前端大屏与详情页在无刷新下更新提醒卡片。
- **对应页面/接口**：`/screen`、`/scenic/:id`（天气面板）；通道 `WS /ws/screen`。

## 3. ECharts GL 3D 四川地图 + 飞线动画

- **一句话**：数据大屏用 3D 四川地图承载景点热力与跨城"飞线"，一眼看清全川旅游热度分布。
- **实现方式**：`echarts-gl` 的 `map3D` + `lines3D` 组合，GeoJSON 四川行政区划 + 景点经纬度点位；飞线用起点终点颜色渐变 + 流动 `effect`；数据由 WebSocket 实时驱动 `setOption`。
- **对应页面**：`/screen`（`src/screen/DataScreen.vue`、`src/screen/components/SichuanMap.vue`）。

## 4. GSAP 滚动叙事 + Lenis 平滑滚动

- **一句话**：首页以整屏滚动叙事呈现"蜀地风光 → 美食 → 文化 → AI"，滚动如丝般顺滑。
- **实现方式**：`Lenis` 提供全局平滑滚动并接入 `GSAP ScrollTrigger`（`scrollerProxy`）；`useScrollReveal` 组合式函数统一入场动画；分节吸附 + 交叉淡入；`requestAnimationFrame` 单循环驱动，保证 60fps。
- **对应页面**：`/`（`src/views/Home.vue`、`src/components/home/*`、`src/composables/useLenis.ts`）。

## 5. 可折叠侧边栏 + 抽屉式移动端适配

- **一句话**：个人中心侧边栏可 240px↔64px 折叠并记忆状态，小屏自动切换为抽屉。
- **实现方式**：`collapsed` 状态写入 `localStorage`（key `shuyun:profile:sidebar-collapsed`）；CSS `transition: width .3s` + flex 内容区同步；折叠态 hover 显示 tooltip；`<768px` 侧边栏改为 `fixed` 抽屉 + 遮罩。
- **对应页面**：`/profile`（`src/views/Profile.vue`）、移动端菜单 `src/layouts/DefaultLayout.vue`。

## 6. 公共三态组件 StateBlock 统一 loading / empty / error

- **一句话**：全站加载/空数据/错误三态收敛为一个组件，视觉与交互完全一致。
- **实现方式**：`StateBlock.vue` 以 `state` prop 切换：loading 为金色骨架屏（3 行 60/80/70%），empty 为蜀锦纹样图标 + 文案 + 可选按钮，error 为金色警示图标 + 重试回调；前台列表/详情页与首页分节统一接入。
- **对应页面**：全部前台页面（`src/components/common/StateBlock.vue`）。

## 7. 数据大屏 WebSocket 实时刷新

- **一句话**：大屏数据秒级自动刷新，无需手动刷新页面。
- **实现方式**：后端定时/事件触发推送，前端 `WebSocket` 长连接监听（`/ws/screen`），增量更新 ECharts 数据与 KPI 数字滚动；断线自动重连。
- **对应页面/通道**：`/screen`（`WS /ws/screen`）。

## 8. 川蜀非遗/文化真实数据模型（100 + 100 + 50 + 100）

- **一句话**：沉淀 350 条川蜀景点/美食/文化/非遗真实数据，建成可扩展的内容底座。
- **实现方式**：编写 `tools/excel2sql.py`（pandas + openpyxl）把 4 个 Excel 转成幂等 SQL（`CREATE TABLE IF NOT EXISTS` + `INSERT ... ON DUPLICATE KEY UPDATE`），自动字段推断、图片路径重写、图片拆子表、城市名→`city_id` 映射；输出 UTF-8 无 BOM。
- **对应数据/接口**：`shuyun-data/*.xlsx` → `shuyun-web/src/main/resources/db/data.sql`；接口 `/api/scenic/*`、`/api/food/*`、`/api/culture/*`、`/api/heritage/*`。
